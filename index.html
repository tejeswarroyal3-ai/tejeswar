            Hierarchical Flow Representation Learning
          

          

            Raw network traffic consists of both intra-packet structural byte correlations and inter-packet temporal dependencies. Our architecture ingests packet payload matrices through a 1D-CNN, feeding local features into a Bidirectional LSTM:
          

          
    
            
  • 1D Convolutional Layers: Learn invariant spatial byte patterns, protocol headers, and entropy distributions across sliding packet windows.
    • 
            
  • Bidirectional LSTM: Captures bidirectional forward and backward temporal sequences (e.g. TCP handshakes, TLS alert exchanges, beacon intervals).
    • 
            
  • Self-Attention Pooling: Dynamically weights critical anomalous packets within long-lived persistent flow sessions.

            Unsupervised Benign Manifold Calibration
          

          

            Zero-day attacks are by definition absent from supervised training labels. To overcome this, Aegis trains a Variational Autoencoder (VAE) exclusively on massive streams of legitimate corporate network traffic to model the normative latent distribution \(p(z)\):
          

          
    
            
  • Latent Compression: Projects 512-dim flow tensors down to a 32-dimensional Gaussian latent bottleneck \(z \sim \mathcal{N}(\mu, \sigma^2)\).
    • 
            
  • Reconstruction Error Metric: Legitimate flows reconstruct with minimal Euclidean loss \(\mathcal{L}_{recon} < 0.05\).
    • 
            
  • Novel Attack Manifestation: An unseen zero-day exploit triggers a dramatic spike in reconstruction loss, immediately isolating it from normal operations.
    • 
          

        

        

          
// LATENT SPACE BOTTLENECK

          

            

              
Dense Encoder Network \(\phi(x)\)

              
Mapping spatial-temporal representations to latent parameters \(\mu, \log \sigma^2\)

            

          

          

            

              
Bottleneck Manifold \(z \in \mathbb{R}^{32}\)

              
KL Divergence Regularization: \(D_{KL}(q(z|x) || p(z))\)

            

            BOTTLENECK

            Extreme Value Theory (EVT) & OpenMax
          

          

            Instead of forcing classifications into closed known classes, Aegis-DL fits a statistical Weibull distribution to the extreme tail distances of each class mean in the penultimate feature layer:
          

          
    
            
  • Mahalanobis Distance \(\mathcal{D}_M(x)\): Calculates exact geometric distance from established cluster centroids.
    • 
            
  • Open-Set Probability Calculation: Flow confidence is revised using Weibull cumulative density functions to dynamically compute \(P(y = \text{ZeroDay} | x)\).
    • 
            
  • Zero-Day Novelty Threshold: If confidence in all known classes decays below open-set bounds, the flow is decisively flagged as an unknown zero-day exploit.

      The Threat Landscape
      
Why Legacy Intrusion Detection Fails on Zero-Days

      

        Modern cyber adversaries exploit undisclosed vulnerabilities (Zero-Days), polymorphic malware, and stealth C2 tunnels that bypass traditional pattern matching and standard supervised machine learning.
      

    


    

      

        

          
        

        
Signature-Based IDS Blindness

        

          Tools like Snort and Suricata rely exclusively on pre-compiled CVE rule databases. A novel zero-day exploit has 0% detection rate until an incident occurs and signatures are manually authored and deployed.
        

      


      

        

          
        

        
Closed-World Supervised DL Trap

        

          Standard classifiers (Random Forest, ResNet) force every unknown flow into existing training labels via Softmax, producing dangerous overconfident false negatives on unseen attack vectors.
        

      


      

        

          
        

        
The Aegis-DL Hybrid Breakthrough

        

          We combine Spatial CNNs & Temporal BiLSTMs with an unsupervised Latent Reconstruction Manifold and Open-Set Recognition to identify novel anomalies with mathematical guarantees.

      Academic Rigor & Theory
      
Mathematical Formulation & Research Paper

      

        Formal objective functions driving the hybrid loss optimization and open-set extreme value attribution.
      

    


    

      

        
1. Joint Hybrid Objective Loss Function

        

          The total network loss \(\mathcal{L}_{total}\) balances supervised multi-class cross-entropy with unsupervised latent reconstruction and manifold regularization:
        

        

          \(\mathcal{L}_{total} = \lambda_1 \mathcal{L}_{CE}(y, \hat{y}) + \lambda_2 \|x - \hat{x}\|_2^2 + \lambda_3 D_{KL}(q(z|x) \,\|\, p(z))\)
        

        

          Where \(\mathcal{L}_{CE}\) is the categorical cross-entropy for known attacks, \(\|x - \hat{x}\|_2^2\) is the VAE mean squared reconstruction error, and \(D_{KL}\) enforces Gaussian latent space priors.
        

      


      

        
2. OpenMax Extreme Value Probability (EVT)

        

          For an input vector \(x\), the zero-day class probability \(P(y = C_0 \,|\, x)\) is computed by redistributing activation margins based on fitted Weibull CDFs:
        

        

          \(P(y = C_0 \,|\, x) = \frac{e^{\sum_{i=1}^N v_i(x) (1 - w_i(x))}}{e^{v_0(x)} + \sum_{i=1}^N e^{v_i(x) w_i(x)}}\)
        

        

          Where \(w_i(x) = 1 - \exp\left(-\left(\frac{\mathcal{D}_M(x, \mu_i)}{\lambda_i}\right)^{\kappa_i}\right)\) represents the Weibull cumulative probability for class \(i\).
